## Slik bruker du illustrasjonene

Illustrasjonene er laget for digitale flater og fungerer både i lys og mørk modus.
Bruk dem som blikkfang på forsider, i introduksjoner og for å bryte opp lange tekster.
Ikke endre farger, proporsjoner eller elementer i illustrasjonene.

Klikk på en illustrasjon for å se detaljer, kopiere SVG-koden eller laste den ned.

## Bruk i kode

Illustrasjonene er tilgjengelige som React-komponenter og som rene SVG-strenger i pakken `@digdir/digdir-design`.

```bash
npm install @digdir/digdir-design
```

```tsx
import { PersonMedJojo } from '@digdir/digdir-design/digdir/illustrations/react';

<PersonMedJojo aria-hidden />
```

For at illustrasjonene skal følge mørk modus, må du også laste inn stilarket:

```ts
import '@digdir/digdir-design/digdir/illustrations/css';
```

Illustrasjonene er dekorative. Legg på `aria-hidden` når de ikke gir informasjon, eller gi dem en `title` når de gjør det.

## Trenger du en ny illustrasjon?

Nye illustrasjoner skal følge formspråket og fargene i profilen. Ta kontakt med KOM før du bestiller eller lager nye illustrasjoner.

Skal du lage en ny illustrasjon? Da burde du lese siden [illustrasjoner - for designeren](/digdir/illustrasjoner/for-designeren).
