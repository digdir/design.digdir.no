<IllustrationLibrary />

## Bruk i kode

Illustrasjonene finnes i pakken `@digdir/digdir-design`, både som React-komponenter og som SVG-tekst.

```tsx
import { ToPersonerVedDatamaskin } from '@digdir/digdir-design/altinn/illustrations/react';

<ToPersonerVedDatamaskin aria-hidden />
```

```ts
import { toPersonerVedDatamaskin } from '@digdir/digdir-design/altinn/illustrations/svg';

element.innerHTML = toPersonerVedDatamaskin;
```

Bruk `aria-hidden` når illustrasjonen er dekorativ, og `title="…"` når den gir informasjon.
