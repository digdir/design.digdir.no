## Bruk i kode

Illustrasjonene finnes i pakken `@digdir/digdir-design`, både som React-komponenter og som SVG-tekst.

```tsx
import { PersonSomTroster } from '@digdir/digdir-design/dodsfall-og-arv/illustrations/react';

<PersonSomTroster aria-hidden />
```

```ts
import { personSomTroster } from '@digdir/digdir-design/dodsfall-og-arv/illustrations/svg';

element.innerHTML = personSomTroster;
```

Bruk `aria-hidden` når illustrasjonen er dekorativ, og `title="…"` når den gir informasjon.
