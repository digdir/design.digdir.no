Komponentene våre er [Designsystemet](https://designsystemet.no) sine komponenter.
Varde legger bare til egne varianter i CSS, så de fungerer med vanlig HTML og uansett rammeverk.

## Installer

```bash
pnpm add @digdir/designsystemet-css @digdir/designsystemet-web @digdir/varde
```

## Importer

```js
import '@digdir/designsystemet-css';
import '@digdir/designsystemet-web';
import '@digdir/varde/components.css';
```

- `@digdir/designsystemet-css` gir stilene til komponentene.
- `@digdir/designsystemet-web` gir oppførsel til web-komponentene, for eksempel `<ds-tabs>`.
- `@digdir/varde/components.css` legger til Varde sine varianter.

Du kan også importere én og én komponent, for eksempel `@digdir/varde/components/tabs.css`.

Se [dokumentasjonen til Designsystemet](https://designsystemet.no/no/fundamentals/code/setup) for mer om oppsett, blant annet hvordan du laster inn tema.
